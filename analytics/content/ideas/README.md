

Este directorio contiene las ideas de contenido de Vitosaurio.

El agente debe utilizar este espacio para:
   •   Generar nuevas ideas.
   •   Guardar ideas pendientes.
   •   Clasificar ideas.
   •   Recuperar ideas antiguas.
   •   Evitar repetir conceptos.
   •   Convertir las mejores ideas en guiones.

⸻

ESTADOS

Cada idea puede encontrarse en uno de estos estados:

💡 IDEA

Concepto inicial todavía sin desarrollar.

📝 DESARROLLO

Idea seleccionada para convertirse en contenido.

🎬 PRODUCCIÓN

Guion y prompt preparados.

📤 PUBLICADO

Contenido publicado y enviado a análisis.

🏆 GANADOR

Contenido que ha demostrado un rendimiento excepcional.

❌ DESCARTADO

Idea que no se utilizará.

⸻

PRIORIDADES

Cada idea debe poder clasificarse:

P1 — PRIORIDAD ALTA

Gran potencial de viralidad o importancia narrativa.

P2 — PRIORIDAD MEDIA

Contenido interesante que merece probarse.

P3 — EXPERIMENTO

Contenido diseñado principalmente para aprender.

⸻

REGLA DE ORIGINALIDAD

Antes de crear una idea nueva, comprobar las ideas existentes.

Evitar repetir exactamente:
   •   El mismo hook.
   •   El mismo chiste.
   •   La misma estructura.
   •   La misma situación.

Si una idea anterior funcionó, crear una evolución, no una copia.
