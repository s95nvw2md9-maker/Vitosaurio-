Vitosaurio — Guiones

Este directorio contiene los guiones de los vídeos de Vitosaurio.

Cada guion debe transformar una idea en una pieza de contenido lista para producir.

⸻

ESTRUCTURA DEL GUION

Cada guion debe contener:

1. INFORMACIÓN

ID:
Título:
Idea original:
Plataforma:
Duración objetivo:

⸻

2. OBJETIVO

Definir qué debe conseguir el vídeo:
   •   Viralidad.
   •   Seguidores.
   •   Comentarios.
   •   Compartidos.
   •   Construcción de personaje.
   •   Continuación de una historia.
   •   Información.
   •   Entretenimiento.

Puede tener más de un objetivo.

⸻

3. HOOK

El inicio debe captar la atención inmediatamente.

Debe ser:
   •   Rápido.
   •   Claro.
   •   Curioso.
   •   Visual o verbalmente potente.

Evitar introducciones innecesarias.

⸻

4. GUION

Dividir el vídeo por momentos.

Ejemplo:

0-2 segundos
   •   Imagen:
   •   Acción:
   •   Diálogo:

2-5 segundos
   •   Imagen:
   •   Acción:
   •   Diálogo:

5-10 segundos
   •   Imagen:
   •   Acción:
   •   Diálogo:

Final
   •   Imagen:
   •   Acción:
   •   Diálogo:
   •   CTA:

⸻

5. VITOSAURIO

Definir:
   •   Qué hace.
   •   Qué dice.
   •   Qué emoción transmite.
   •   Cómo interactúa con Víctor.
   •   Cómo interactúa con el entorno.

Vitosaurio debe sentirse como un personaje activo y no como decoración.

⸻

6. PRODUCCIÓN

Especificar:
   •   Localización.
   •   Personajes.
   •   Objetos.
   •   Vestuario.
   •   Iluminación.
   •   Cámara.
   •   Movimiento.
   •   Sonido.
   •   Música.
   •   Efectos.

⸻

7. PAYOFF

Definir cuál es el momento que recompensa al espectador por haber visto el vídeo.

Puede ser:
   •   Chiste.
   •   Giro.
   •   Reacción.
   •   Descubrimiento.
   •   Situación absurda.
   •   Momento emocional.
   •   Información 8. CTA

Utilizar una llamada a la acción solamente cuando aporte valor.

Ejemplos:
   •   Pregunta para generar comentarios.
   •   Invitación a seguir la aventura.
   •   Pregunta sobre el siguiente destino.
   •   Invitación a compartir.

⸻

CONTROL DE CALIDAD

Antes de aprobar un guion comprobar:
   •   Hook fuerte.
   •   Ritmo adecuado.
   •   Vitosaurio tiene personalidad.
   •   Existe interacción o situación interesante.
   •   Hay payoff.
   •   El vídeo se entiende sin contexto.
   •   No existe información innecesaria.
   •   No contradice AGENTS.md.
   •   No copia innecesariamente contenido anterior.

⸻

RELACIÓN CON EL SISTEMA SELF-IMPROVING

Después de publicar el vídeo:
	1.	Registrar sus métricas en analytics/performance.md.
	2.	Analizar el resultado.
	3.	Actualizar memory/learnings.md.
	4.	Utilizar los aprendizajes para mejorar futuros guiones.

Un guion nunca debe considerarse simplemente “terminado”.

Su rendimiento posterior debe utilizarse para mejorar el siguiente.
